# Contributing

Contributions are welcome through pull requests. Keep `SKILL.md` as the entry point and keep the skill usable when its four files are copied as one directory. Describe the commands you ran to check the change (at least `python3 -m py_compile *.py` and a `run.py --help` or `run.py info` call). Discuss larger changes, such as new providers or non-macOS key storage, in an issue first.

Issues should include the version or commit, agent and version, macOS version, uv version, expected behavior, actual behavior, and a minimal example. Remove API keys, ledger entries, memory notes, and private prompts before posting.

Security reports belong in [SECURITY.md](SECURITY.md), not public issues.
