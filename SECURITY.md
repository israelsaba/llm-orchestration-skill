# Security Policy

Do not report key leaks, prompt-injection concerns, or other vulnerabilities in public issues, and never post API keys, ledger files, or memory notes.

Use GitHub private vulnerability reporting or contact the repository owner through GitHub. Include the affected commit, safe reproduction steps, impact, and a remediation suggestion when possible.

This skill reads API keys from the macOS Keychain and sends prompts and attached files to third-party model providers. Treat everything passed to `complete` as leaving your machine.
